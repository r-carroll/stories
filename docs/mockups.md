### Design Notes
*   **Colors**: Deep Charcoal (#1A1E23) background provides a night-time feel, while Ember Orange (#FF7D45) accents draw attention to active stories.
*   **Home Screen**: Glowing avatars indicate friends with "Untold Stories", creating a subtle urgency.
*   **Exchange Screen**: The split view clearly separates "What I need to give" (Satchel) from "What awaits me" (Offerings), with the lock icon reinforcing the physical meetup requirement.
